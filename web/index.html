✽ cicoria Docs GitHub

Work with several coding agents at once. Know which one needs you.

cicoria runs your coding agents in your terminal, each in a session of its own. It shows which session is waiting for you, keeps everything each one changed ready to review, and sends your notes on the code back as one message.

curl -fsSL https://henomis.github.io/cicoria/install.sh | sh

    Know which agent needs you, without checking
    
          
    Every session shows whether it is working, waiting for your answer, or finished while you were elsewhere, and for how long. ctrl+a a jumps to the next one that needs input, and a desktop notification tells you when one you are not looking at starts waiting.

    Review everything it did, commits included
    
          
    Work the agent has already committed is still there to review: one key counts the changes from the commit the session started on. Diffs open on the whole screen, with search and jumps between hunks, Markdown files as the documents they describe, and ctrl+a h starts the count again once you have looked.

    Review the agent like a pull request
    
          
    Select the lines you mean in a file or a diff and write what you think. When you are done, all your notes go to the agent as one message that names each file and its lines and quotes them.

    Pass a question from one session to another
    
          
    ctrl+a k puts your question to another session. Its answer is handed back to the session you asked from, with your question and what to do next, so you stop copying between panes. The agents never contact each other on their own.

    Two agents on one repository, each in its own worktree
    
          
    Create a session where another one already works and cicoria offers it a git worktree and a branch of its own, so their changes never mix. Closing the session offers to remove the worktree, and the branch stays.

    Close the terminal, pick up where you left off
    
          
    Sessions come back with their names, directories, notes and queues, and Claude Code, Copilot CLI and Codex CLI resume their conversation. Queues return paused, so opening cicoria never sends anything by itself, and ctrl+a w opens another saved workspace.

    The whole project beside the agent
    
          
    See what the agent touched without leaving it. The files panel marks changed files with git's letter and lists what git ignores in grey. @ mentions a file to the agent, e opens it in your editor, and o hands an image or a web page to the system.

    Any agent, with nothing of its interface lost
    
          
    An agent is a command line in a real terminal, so its own interface works as it does alone, and the wheel scrolls back through what left the screen. Claude Code, GitHub Copilot CLI and Codex CLI report their status and the end of their turn through hooks. For other agents the status is guessed from the terminal, and queued messages are sent by hand.

The first minute

    
    
      
  1. 
        
    Install it. You need git and the agents you want to run. Claude Code is the default, and GitHub Copilot CLI and Codex CLI are known too. It is tested on Linux and runs on Windows in WSL2. There are builds for macOS, not yet tried on a Mac.
    
        
    curl -fsSL https://henomis.github.io/cicoria/install.sh | sh
    
      
    2. 
      
  2. 
        
    Open it on a project. The first session starts, and what you type goes to the agent.
    
        
    cd ~/src/app
cicoria
    
      
    3. 
      
  3. 
        
    Press ctrl+a then c for another session: pick the agent, the directory it works in, and a name.
    
      
    4. 
      
  4. 
        
    Press ctrl+a then ? for every key, or ctrl+a then space to find a command by name. The mouse works too. The rest is in the docs.
    
      
    5. 
    

  


  

    
Start the agents, keep working, and switch to the one that needs you.

    

      curl -fsSL https://henomis.github.io/cicoria/install.sh | sh

Cicoria is Italian for chicory. One grows in the agent pane each time you start. The idea turned up at 5:15 one October morning; the name came later that morning, from the chicory its author was cooking while an agent wrote the first version. Only the agent said when it needed attention.
