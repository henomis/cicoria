✽ cicoria Docs GitHub

Run several coding agents side by side, and see which one needs you.

cicoria is a workspace for your terminal. Each agent runs as its own program in a real terminal pane. Around it you get every session with its status, the files, and what changed.

go install github.com/henomis/cicoria/cmd/cicoria@latest

Read the docsSource on GitHub


      
A drawing, not a recording. Click a session, or focus it and press 1, 2, 3 as you would after ctrl+a.

    A status for every session
    
          
    Working, waiting for your answer, or finished while you were elsewhere, and for how long. ctrl+a a takes you to the next session that needs input, and a desktop notification tells you when one starts waiting in the background.

    Any agent, with its own interface
    
          
    An agent is a command line. cicoria runs it in a terminal of its own, so nothing of its interface is lost. Claude Code reports its status through hooks; for the others it is guessed from what the terminal does.

The first minute

    
    
      
  1. 
        
    Install it. You need Go 1.26 or later, git, and the agents you want to run. Claude Code is the default.
    
        
    go install github.com/henomis/cicoria/cmd/cicoria@latest
    
      
    2. 
      
  2. 
        
    Open it on a project. The first session starts, and what you type goes to the agent.
    
        
    cd ~/src/app
cicoria
    
      
    3. 
      
  3. 
        
    Press ctrl+a then c for another session: pick the agent, the directory it works in, and a name.
    
      
    4. 
      
  4. 
        
    Press ctrl+a then ? for every key, or read the docs.

Cicoria is Italian for chicory. One grows in the agent pane each time you start. The name turned up at 5:15 one October morning, and the first version was written by an agent while its author cooked chicory. Only the agent said when it needed attention.
